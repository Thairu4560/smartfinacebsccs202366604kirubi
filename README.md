# 📱 SmartFinance App

## 📌 Project Overview

**SmartFinance** is a mobile application developed using Flutter to help first-year university students manage their finances independently and responsibly.

The app provides tools for budgeting, expense tracking, savings management, and financial education.

---

## 🎯 Objectives

### Main Objective

To develop a mobile application that offers financial education and tools to support students in managing their finances effectively.

### Specific Objectives

* Provide educational modules on personal finance
* Include budgeting and expense tracking features
* Deliver saving tips and reminders
* Create interactive quizzes for self-assessment
* Analyze spending patterns and suggest improvements

---

## 🚀 Features

### 💰 Income Management

* Add and manage income sources (allowance, part-time jobs)

### 💸 Expense Tracking

* Record expenses by category (food, transport, rent, etc.)
* View total expenses and recent transactions

### 📊 Budgeting

* Track spending against income
* View remaining balance

### 💾 Savings Management

* Automatically calculate savings
* Track savings rate
* Set and monitor savings goals

### 📈 Spending Analysis

* Analyze expenses by category
* Detect overspending
* Provide financial suggestions

### 📚 Financial Education

* Learn personal finance concepts
* Improve financial literacy

### 🧠 Quiz Module

* Test financial knowledge
* Get feedback and scores

### 👤 Profile Screen

* View user details
* See financial summary and progress

---

## 🛠️ Technologies Used

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Thairu4560/smartfinacebsccs202366604kirubi.git
```

2. Navigate into the project:

```bash
cd smartfinance
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the app:

```bash
flutter run
```

---

## 📱 APK Build

To generate APK:

```bash
flutter build apk --release
```

APK location:

```
build/app/outputs/flutter-apk/app-release.apk
```
